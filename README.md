# JOB_PULSE_REALTIME

Realtime personal job monitoring console built with OpenAI Sites.

The product consolidates official company job postings, monitors source health,
matches saved keywords, prepares email alerts, and provides an assisted Talent
Community registration queue.

## Delivery sequence

1. Frontend shell with realistic fixture data.
2. Sites D1 schema and sanitized workbook import.
3. ATS/API/HTTP monitoring adapters.
4. Internal webhook events, keyword matching, and email delivery.
5. Assisted Talent registration harness.

## Privacy boundary

This public repository must not contain resumes, application records,
confirmation screenshots, personal contact information, credentials, raw email
content, or unsanitized workbook exports.
